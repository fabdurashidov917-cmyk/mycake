## 🚀 GitHub Pages-ga Yuklash Qo'llanmasi (3 Qadam)

1. **GitHub-da yangi repozitoriy yarating:**
   - [github.com/new](https://github.com/new) manziliga kiring.
   - Repository name: masalan, `mycake` deb nomlang.
   - **Public** qilib belgilang va **Create repository** tugmasini bosing.

2. **Fayllarni yuklang:**
   - **"uploading an existing file"** havolasini bosing.
   - Ushbu papkadagi barcha fayllarni: `index.html`, `.nojekyll`, `README.md` va `assets` papkasini brauzer oynasiga tortib tashlang (drag & drop).
   - **Commit changes** tugmasini bosing.

3. **GitHub Pages-ni yoqing:**
   - Repozitoriyning **Settings** bo'limiga kiring.
   - Chap tomondan **Pages** bo'limini tanlang.
   - **Branch** qismida `main` (yoki `master`) va `/ (root)` ni tanlab, **Save** tugmasini bosing.
   - 1-2 daqiqada sizga bepul ishlovchi veb-sayt havolasi beriladi (masalan: `https://username.github.io/mycake/`).
